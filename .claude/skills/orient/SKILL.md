# Orient

Read root GOAL.md, STATE.md and BENCHMARKS.md, then `git status --short` and the current
branch/commit. On a fresh box follow SETUP.md and restore/verify the active handoff.
Do not read archived hypotheses, skills or changelogs to get oriented. Read only the
current dated changelog if STATE.md leaves a specific ambiguity.

From belief-transfer/, `uv run --no-sync python scripts/handoff.py status` reports the
active inventory and local restore/save receipt; `verify` checks the recorded hashes.
A receipt is evidence of a snapshot, not evidence that a later live process finished.
Inspect actual outputs/logs/checkpoints before marking progress complete.

Briefly report: what is established, what is running or blocked, the recorded next step,
and any discrepancy between notes and actual files. Continue authorized work using the
current plan. Do not launch a full experiment merely to orient or revive historical jobs.
