# Prospective execution amendment: saved checkpoint coverage

This amendment is written before training or new candidate outcomes. It supplements
the frozen BASE reasoning replay plan without changing its data, optimizer settings,
final-only primary endpoint, rejection criteria or independent confirmation bank.

The repository rule requires all100beliefs on each saved checkpoint. Therefore the
step227midpoint receives the same128procedural,256decision and full100belief readings
as the final adapter. Step454also receives those readings unless both its adapter
weights and configuration bytes exactly match final; a hash-bound alias then records
one shared measurement without duplicate calls. Trainer states must identify steps227
and454. If either byte hash differs, step454is measured independently.

Midpoint/terminal results describe the trajectory. They cannot rescue a failed final,
select weights/settings on ethical outcomes, or trigger independent confirmation.
Scientific failures do not suppress full100readings or later checkpoint collection;
technical identity/execution failures preserve partials and stop without restart.
The fixed final passes only the original procedural retention criteria, held/eval
decision retention criteria, complete/strict replies in all four decision cells,
original qualification,2400valid natural replies and fresh model controls. Seen cells
remain diagnostic. Native assessments, raw replies, unscorables and all failures remain.

Conditional independent confirmation is executable and frozen before training. It is
launched only after the final development pass and complete agent review have been
saved privately. There is no automatic confirmation, checkpoint adoption or extension.
All flagged replies require full inspection. Failed or partial runs retain their IDs.
