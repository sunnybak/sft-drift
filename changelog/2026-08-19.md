# 2026-08-19

## Added

- `stage=writeup`: a grounded, LLM-assisted short-paper path. It reads only declared
  result-run artifacts, retains the complete `evidence.json` input, drafts structured
  prose, reviews it for unsupported claims, renders a fixed LaTeX template, and records
  its own `RunResult`.
- `configs/run/paper_factory_farming_v1.yaml`, which points at the step-24 reading and
  the endpoint trajectory as separate, declared evidence bundles.
- A deterministic LaTeX template plus tests for evidence grounding, figure provenance,
  Markdown report integration, and compilation output handling.
- `tools/visualize_codebase.py`, a standard-library-only generator for a self-contained
  HTML architecture map covering package layers, imports, stage dispatch, config overlays,
  artifact flow, module concerns, and the repository's structural invariants.

## Changed

- `analysis.markdown` now renders copied writeup figures and a Manuscript section, so
  `report.md` remains the common review surface for measurement and paper artifacts.
- Paper and Markdown tables now use one deterministic `analysis.tables` presentation layer.
  The paper records endpoint and primary-reading choice gates separately, then the endpoint
  absorption table with held-out pair counts, CIs, netting pairs, and a two-sided verdict.
- `writeup.primary_reading` explicitly identifies the run used for belief/action
  interpretation; the factory-farming paper pins it to `matrix_v1_step24`.
- The belief/action figure is now a checkpoint-coloured scatter with arm-specific markers,
  not connected paths. Its title and paper caption explicitly mark raw arm scores as
  diagnostic rather than a netted transfer estimate.
- `paper_factory_farming_v2` is a new, versioned paper bundle. It regenerates both figures
  from `matrix_v1/trajectory.jsonl` without modifying the source run, and persists the
  target belief, downstream action, primary/endpoint readings, and interpretation rules in
  `evidence.json` before drafting.
- `paper_factory_farming_v4` replaces the hard-to-read belief/action phase-space diagnostic
  with a four-panel optimizer-step figure: belief/action rows and positive/negative columns,
  with the evidence, control, and explicit arms in each panel.
- `paper_factory_farming_v5` makes every line solid in that split figure and labels columns
  as positive- and negative-statement conditions; polarity is now carried by panel placement,
  rather than a redundant dash convention.
- `paper_factory_farming_v6` stops expanding narrow result tables to the full text width
  and stacks the main trajectory panels vertically, giving every chart the page width rather
  than three compressed subplots.

## Learnings

- Tectonic's first compilation downloads its package bundle and exceeded the original
  60-second cap. The writeup compiler now allows 180 seconds; the retry completed in
  18 seconds once the bundle was cached.
- `paper_factory_farming_v1` compiled successfully from `matrix_v1` and
  `matrix_v1_step24`. The rendered paper correctly foregrounds the exploratory scope:
  selected endpoint absorption, no stable downstream transfer claim, no step-24
  absorption read, control dependence, and one seed.
- A paper source must remain read-only. `collect_evidence` now renders a missing source
  report in memory instead of rewriting historical `report.md`; every table is stamped
  in `evidence.json` with its originating artifact's full SHA-256.
