# Historical snapshot — 2026-10-17

Preserves the instructions, planning, hypotheses, notes and session history before
the fresh ethical-stance SFT study. These are historical records, not an active queue.
The original directory layout is retained inside this snapshot where practical.
Earlier archives remain alongside this one.

One-off scripts are preserved under `belief-transfer/scripts/`; their original root
assumptions may require checking out the historical commit to reproduce them.
`moved_scripts.json` inventories the moved paths. No experimental observations,
checkpoints, banks or falsifiers were changed or deleted. Old run configs remain at
their original paths because tests and inherited configs still use them.

Start at the repository-root `SETUP.md`, `GOAL.md` and `STATE.md`.
